# 和意为

<img src="assets/icon.svg" width="80" height="80" alt="和意为图标">

**论文读不懂，先留一个问号。**

一个简单的 Zotero PDF 阅读插件。没有 AI、没有聊天框；你负责困惑，它负责留下 `?`。

## 使用

| 操作 | 效果 |
| --- | --- |
| 选中文字，点浮层里的 **?** | 在文字末尾留下问号 |
| 点阅读器工具栏 **?**，再点论文 | 在点击位置留下问号 |
| **⌘/** | 有选区时直接标记；没有选区时进入点击放置模式 |
| **Esc** | 退出放置模式 |
| **⌘Z** | 使用 Zotero 原生撤销 |

七个问号从鼠标旁弹出，正文只留下一个。相同页面约 14 PDF 点内的重复问号会合并，避免连按制造问号森林。普通输入、搜索框和批注编辑框不接管快捷键。动画尊重系统的“减少动态效果”偏好。

## 安装

适用：**macOS + Zotero 10.0.x**，开发与集成验证版本为 Zotero 10.0.6。其他系统及 Zotero 大版本尚未验证。

1. 在 [GitHub Releases](https://github.com/AlexGrandbell/zotero-wdim/releases/latest) 下载最新版 `.xpi` 安装包。
2. 打开 Zotero → **工具 → 插件**，将安装包拖进窗口。
3. **安装或更新后重启一次 Zotero**，再打开 PDF 使用。

如果从源码构建，安装包位于 `dist/`。插件 ID 保持不变，已有的 WDIM 本地版本可以覆盖更新。

## 批注与隐私

- 保存为 Zotero 原生 **文字批注**，内容只有 `?`，支持正常撤销、删除与批注管理。
- 批注默认保存在 Zotero 数据库，不直接改写原始 PDF。要在 macOS 预览等其他软件中显示，请从 Zotero 导出带批注的 PDF 副本。
- 关闭或卸载插件不会删除已有问号。只读资料库不写入。
- 阅读和批注功能不向外部发送文献、选区或鼠标位置，没有遥测，不需要 AI 服务或 API Key。
- 如启用 Zotero 同步，批注遵循 Zotero 的同步设置。插件更新清单由 Zotero 的更新机制读取。

## 验证范围

29 项行为测试以及 Zotero 10.0.6 独立测试环境中的 32 项集成检查通过。集成检查使用模拟事件，覆盖三个不同的鼠标位置及实际动画布局。原用户已反馈重启后可正常使用。

扫描 / 旋转 PDF、跨设备同步和导出副本在其他阅读器中的效果尚未完整人工验收。详细记录见 [VALIDATION.md](VALIDATION.md)。

## 开发

行为测试需要 Node.js 22+，打包需要 Python 3.9+，无第三方运行时依赖。

```sh
npm test
npm run build
```

公开发布使用 `python3 scripts/build.py --release`，它会拒绝保留域名更新地址。XPI 只包含运行时代码、图标、清单和许可证，构建同时输出 SHA-256 校验和。

工具栏及选字菜单使用 Zotero Reader 的事件接口；PDF 点位和原生批注管理仍使用阅读器内部接口。Zotero 大版本更新后应先复测，再放开兼容范围。
