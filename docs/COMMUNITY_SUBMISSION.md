# 中文社区收录申请草稿

标题：`[新插件收录] 和意为：为读不懂的论文留一个问号`

插件名称：**和意为**

仓库地址：https://github.com/AlexGrandbell/zotero-wdim

发布 / 下载：https://github.com/AlexGrandbell/zotero-wdim/releases/tag/v0.1.3

许可证：MIT。

支持环境：macOS，Zotero 10.0.x；集成验证版本 10.0.6。

简介：选中文字或点击 PDF 页面，留下一个内容只有 `?` 的 Zotero 原生文字批注。支持 `⌘/` 快捷键、鼠标旁七连问号动画、同位置连按去重、原生撤销与删除。无 AI、无账号要求，不上传文献内容。

测试情况：29 项行为测试、32 项独立 Zotero 集成检查通过。集成测试为模拟事件；扫描 / 旋转 PDF、导出副本显示、跨设备同步仍有待更完整人工验收。

申请入口：https://github.com/zotero-chinese/zotero-plugins/issues/new

收录与上线时间由社区维护者决定。
